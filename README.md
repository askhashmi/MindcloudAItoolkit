# Mind Cloud .sa — منصة بيع الملفات الرقمية 🇸🇦

منصة متكاملة لبيع الملفات الرقمية (كتب إلكترونية، قوالب، دورات، تصاميم، أدوات) مبنية بالكامل وفق
**دليل الهوية البصرية الرسمي لـ Mind Cloud**، بواجهة عربية RTL وخط Cairo.

> **نسخة تجريبية Front-End:** تعمل بالكامل في المتصفح بدون خادم — البيانات (المستخدمون، المنتجات،
> الطلبات، الرسائل) تُخزَّن في `localStorage`. طبقة البيانات معزولة في `assets/js/store.js`
> بحيث تُستبدل لاحقًا بنداءات API حقيقية دون تغيير الصفحات.

## 🚀 التشغيل

لا يحتاج أي تثبيت — افتح `index.html` مباشرة، أو شغّل خادمًا محليًا:

```bash
python3 -m http.server 8000
# ثم افتح http://localhost:8000
```

## 🔑 حساب الأدمن الافتراضي

| البريد | كلمة المرور |
|---|---|
| `admin@mindcloud.sa` | `Admin@123` |

سجّل الدخول به ثم افتح **لوحة التحكم** من زر الترويسة أو عبر `admin/index.html`.

## 📁 مراحل المشروع والصفحات

### المرحلة 1 — الأساسات
- `assets/css/style.css` — نظام التصميم الكامل (ألوان الهوية، مكوّنات، استجابة)
- `assets/js/store.js` — طبقة البيانات (مستخدمون، منتجات، سلة، طلبات، رسائل، إعدادات)
- `assets/js/app.js` — الترويسة/التذييل المشتركان، التنبيهات، حراسة الصفحات

### المرحلة 2 — الصفحات العامة
- `index.html` — الرئيسية (بطل، مزايا، إحصائيات، منتجات مميزة، خطوات الشراء)
- `products.html` — المنتجات (بحث + تصفية حسب التصنيف)
- `about.html` — عن المشروع (القصة، الهدف، الرسالة، القيم)

### المرحلة 3 — الحسابات
- `auth.html` — التسجيل / تسجيل الدخول (تبويبان في صفحة واحدة)
- `account.html` — الحساب الشخصي: **مشترياتي مع التحميل**، سجل الطلبات، تعديل البيانات

### المرحلة 4 — الشراء
- `checkout.html` — السلة + الدفع (مدى / بطاقات / Apple Pay — محاكاة) مع ضريبة القيمة المضافة
- `confirmation.html` — تأكيد الطلب + تحميل الملفات فورًا

### المرحلة 5 — الدعم وصفحات مقترحة إضافية ✨
- `contact.html` — التواصل والدعم الفني (تذاكر تصل للوحة التحكم)
- `faq.html` — الأسئلة الشائعة *(مقترحة)*
- `terms.html` — الشروط والأحكام وسياسة الخصوصية *(مقترحة)*

### المرحلة 6 — لوحة التحكم (`admin/`)
- `admin/index.html` — نظرة عامة: إيرادات، طلبات، مستخدمون، رسائل، الأكثر مبيعًا
- `admin/products.html` — إدارة المنتجات (إضافة/تعديل/إيقاف/حذف)
- `admin/orders.html` — إدارة الطلبات وتغيير حالاتها وعرض تفاصيلها
- `admin/users.html` — إدارة المستخدمين (ترقية لمدير، إيقاف، حذف)
- `admin/messages.html` — تذاكر الدعم (عرض، رد، إغلاق)
- `admin/settings.html` — إعدادات المنصة (محتوى الرئيسية، الضريبة، التواصل، إعادة التهيئة)

## 🧭 مقترحات للمرحلة القادمة
- صفحة تفاصيل لكل منتج مع معاينة ومراجعات العملاء
- كوبونات خصم وبرنامج إحالة
- ربط بوابة دفع سعودية مرخّصة (Moyasar / Tap / HyperPay) وخادم حقيقي لتسليم الملفات بروابط موقّعة
- لوحة بائعين لصنّاع المحتوى (نموذج Marketplace)
- إشعارات بريدية تلقائية للطلبات وتذاكر الدعم
